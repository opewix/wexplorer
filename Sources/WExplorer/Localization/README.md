# Локализация

Все надписи интерфейса хранятся здесь, а не в коде.

- `Strings.swift` — перечисление `Str` с ключами всех строк.
- `Languages/<Язык>.swift` — таблица строк одного языка: `[Str: String]`.
- `L10n.swift` — выбор языка и функция `tr(.key, аргументы...)`.

В тексте строки подстановки пишутся как `{0}`, `{1}` — по порядку аргументов:
`tr(.diskFree, free, total)` → «Свободно: {0} из {1}».

## Как добавить язык

1. Скопируйте `Languages/English.swift`, например, в `Languages/German.swift`.
2. Переименуйте свойство (`static let german`), укажите код ISO 639-1 (`code: "de"`)
   и самоназвание языка (`name: "Deutsch"`), переведите строки.
3. Добавьте язык в список `L10n.languages` в `L10n.swift`.

Больше ничего делать не нужно: язык появится в меню «Сервис → Язык»,
а `scripts/bundle.sh` сам добавит его код в `Info.plist`, чтобы системные
надписи (типы файлов, кнопки стандартных диалогов) тоже переводились.

Строки, которых нет в переводе, берутся из английского. Отладочная сборка
(`swift build`) при запуске печатает список непереведённых ключей.

## Как добавить строку

1. Добавьте ключ в `Str` (`Strings.swift`) в подходящую группу.
2. Добавьте текст во все файлы `Languages/*.swift`.
3. В коде используйте `tr(.новыйКлюч)`.
