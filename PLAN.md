# WExplorer — клон Windows XP Explorer для macOS

Цель: приложение, максимально похожее на Проводник Windows XP (тема Luna) по виду и поведению.

## Решения

- **Стек:** Swift + AppKit (нативно, быстрые файловые операции, QuickLook, корзина, Spotlight).
- **Отрисовка:** кастомная. Заголовок окна, меню, тулбар, панели рисуются самим приложением в стиле Luna.
- **Ресурсы:** оригинальные иконки и шрифт Tahoma/Segoe — собственность Microsoft. Используем свои или свободные аналоги (иконки в стиле XP рисуем/берём с открытой лицензией, шрифт — Tahoma-подобный, например Noto Sans / DejaVu Sans). Не распространять с оригинальными ресурсами.
- **Минимальная версия macOS:** 13+.
- **Рамка окна:** родная macOS (заголовок, светофор, fullscreen). Стиль XP — только внутри окна: меню, тулбар, адресная строка, панели, список.
- **Горячие клавиши:** как в macOS (Cmd+C/X/V/A, Cmd+Z), а не Ctrl. Системное меню остаётся минимальным, чтобы шорткаты работали.
- **Сборка:** SwiftPM без Xcode (`swift build`, `scripts/bundle.sh` собирает `build/WExplorer.app`).

## Структура окна (эталон XP)

1. Заголовок окна (синий градиент Luna, кнопки свернуть/развернуть/закрыть)
2. Строка меню: Файл, Правка, Вид, Избранное, Сервис, Справка
3. Стандартная панель: Назад, Вперёд, Вверх, Поиск, Папки, Виды
4. Адресная строка (выпадающий список + кнопка «Переход»)
5. Левая панель: либо «Задачи» (File and Folder Tasks, Other Places, Details), либо дерево папок
6. Основная область: список файлов
7. Строка состояния (число объектов, размер выбранного)

## Оценка

MVP (этапы 0–2): 1–2 недели. Полноценная версия (этапы 0–6): 4–6 недель в одиночку.

## Риски

- Кастомная отрисовка всех контролов занимает больше времени, чем кажется. Начинаем с самого заметного: заголовок, тулбар, дерево.
- Точный вид Luna придётся сверять по скриншотам XP. Собрать эталонные скриншоты заранее в папку `reference/`.
- Права доступа macOS: без Full Disk Access часть папок недоступна.
- Юридически: не использовать оригинальные ресурсы Microsoft в публичных релизах.

## Структура репозитория (предложение)

```
wexplorer/
  PLAN.md
  reference/          # скриншоты XP для сверки
  WExplorer/
    App/              # AppDelegate, окно
    Theme/            # Luna: цвета, градиенты, шрифты
    Views/            # тулбар, адресная строка, панели, список, дерево
    Model/            # FileItem, загрузчик, история навигации
    Operations/       # копирование, перемещение, удаление, прогресс
    Resources/        # иконки, звуки (свои/свободные)
```
